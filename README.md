# fehlerfuchs-3d-weiterleitung

Kleine Weiterleitungsseite für die Kurzadresse `3d.fehlerfuchs.eu` (GitHub Pages, damit die Adresse ein Zertifikat bekommt).

- `CNAME`: die Kurzadresse
- `index.html` und `404.html`: leiten jede Adresse auf das Ziel weiter (Meta-Refresh, Skript, `canonical`)
- Ziel zurzeit: `https://fehlerfuchs.eu/`. Sobald die Seite `/3d/` live ist, in beiden HTML-Dateien auf `https://fehlerfuchs.eu/3d/` umstellen (drei Stellen je Datei).

Betreut von FehlerFuchs. Die Webseite selbst liegt in `FehlerFuchs/fehlerfuchs-website`.
